## Locked design decisions
- Full design: `GAME_DESIGN.md` (8 zones, Misconception bosses, hybrid Field Quests, Echo spaced-repetition encounters).
- Energy = **Insight** (corrupted form wielded by bosses = **Doubt**). Correct answers grant +1 Insight (cap 5).
- Tactical kit (fun-gate v3): after each correct answer choose — Tome Strike (1◆), Insight Lance (3◆, beam), Focus (free — bank Insight, no attack), or CLARITY MEND (5◆, heal 8 — always less than redemption's 10+2c; DISABLED while boss is coiled so it can't dodge coils; no graze). NO defensive tech (Ward cut as too easy). Insight persists through misses; streak/surge reset on miss. Surge only discharges on damaging techniques, so Focus preserves it → bank-bank-Surged-Lance is the high-roller line. v4: Focus provokes a graze (6 HP — guard drops), so banking trades HP for power; redemption heal (+10) when a previously-missed question is answered correctly on requeue (fixing your misconception literally heals you).
- Insight Surge: streak ≥3 arms it; doubles next damaging technique; gold spark burst + ambient sparkle when armed.
- **Mega Man progression:** each defeated boss's technique is purified and absorbed into the player's kit (fiction + mechanics).
- Missed questions requeue ~2 slots later in the same fight. Fights need deep question pools (banking slows kills) — 12+ per boss minimum.
- **Text auto-fit (accessibility, creator-requested — players may have impaired vision):** fitText() renders every question at the LARGEST font size that fits the panel (tries 13→9px), so typical questions get maximum readability and only monster questions step down. Tech menu fixed 12px, reteach banner 11px, study lessons 12px. Do not regress to fixed small fonts.
- **Choice text word-wrap + dynamic layout (bug fix, creator-reported):** answer choices had NO wordWrap at all — content up to 92 chars (real authored max) ran off-panel. Fixed: choice font 9px + wordWrap(W-60), lines stack dynamically via layoutLines()/choiceStartY() based on actual rendered height (never a fixed y-offset again). Panel enlarged 124→142 tall, prompt font 9px, prompt/choice positions all computed from measured text height — this must stay dynamic since content length varies per authored question (max prompt 190 chars / 3 lines, verified via `?fq=zoneIdx:qIdx` debug hook).
- **TOTAL RECALL finisher (creator-requested):** pool exhausted + boss alive → cinematic finisher (charge-up, 3 staggered full-screen beam+lightning bolts (glow+core rect spans edge-to-edge, jagged flickering Graphics zigzag traced on top per creator request), white flash, remaining-HP damage number), victory text variant, stats.finishers++. Sim-proved unreachable in base game (intended: mythical). **Full Guard** cfg flag (cycle ≥1 only): Focus at 5◆ = no graze, '[FULL GUARD]' menu tag + cyan ring anim — the deliberate Echo-only path to the finisher. Test hooks: `?qdebug` = 3-question unshuffled pool; `?echo` = Echo (cycle-1) rules at base; `?fq=zoneIdx:qIdx` = force one exact question (for testing long-content layout). **Doubt Coils v3 (creator re-tuned twice — coils must be a CONSTANT presence)**: coilChance = 35% at Echo 1, +2%/cycle, cap 45%. Sim: masters finisher ~10% at E1 (properly mythical — creator accepts feel over finisher generosity). Telegraph is LOUD (red camera flash + shake + '!' popup + pulsing red aura rect + 11px pulsing text) — creator found the quiet version missable. Coils PIERCE Full Guard: brimming Insight blunts to normal graze ('PIERCED -X'), unguarded coil crits ×2; any damaging tech disperses; bossAttack (miss punish) NEVER crits. Sim: masters ~28-31% finisher success. **Echo Rites interstitial** (ZoneMapScene.showEchoRites) shows before every cycle start: Doubt Coils, Full Guard, and the TOTAL RECALL legend — the finisher is discoverable without natural encounter (creator-requested tutorial callout). ## Gotchas
- **`textures.exists()` is TRUE before a base64 texture DECODES (v1.0.5, real player crash 'could not enter the Micromanager fight'):** in the single-file prod build every sprite is a base64 data URI decoded ASYNC via addBase64. `textures.exists(key)` returns true the instant the key is REGISTERED — but rendering an Image before its source decodes makes Phaser's Canvas renderer call `drawImage(null)` and hard-crash the WHOLE game (uncaught). Repro'd only in the Claude desktop Electron/srcdoc webview (slower/flakier decode), never in headless Chromium — so headless verification can't catch it; reason about the async path. FIX: `scenes/tex.ts` `texReady(scene,key)` = exists AND getSourceImage() has width/height > 0. ALL sprite add.image guards use it (BattleScene boss/player/companion/pet, Overworld pet, Celebration, Companion) → an un-decoded/failed texture falls back to the existing placeholder rect (ugly boss > hard crash that blocks progress forever). NEVER guard a rendered sprite on bare textures.exists(); use texReady.
